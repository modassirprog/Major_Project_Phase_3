# Project summary

**Project:** Machine Learning-Based Early Prediction of Bipolar Disorder Using Multimodal Clinical and Behavioral Data

**Prototype scope today:** A working research dashboard for current bipolar-label classification from the supplied symptom/criteria-style CSV. The implementation compares model discrimination and calibration and demonstrates a simulated missing-feature stress test.

**Important scope correction:** The supplied CSV does not visibly provide multimodal sensor data, timestamps, longitudinal outcomes, or separate clinical-site identifiers. Therefore, this version should be presented as an initial prototype / baseline, not as a completed early-prediction or external-validation system.
